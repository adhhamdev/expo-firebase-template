# Assets

Add at minimum:

| File | Purpose |
|------|--------|
| `icon.png` | App icon (1024×1024) |
| `adaptive-icon.png` | Android adaptive foreground |
| `splash-icon.png` | Splash mark |
| `notification-icon.png` | Android notification (white alpha) |

Update paths in `app.config.ts` if you rename files.
