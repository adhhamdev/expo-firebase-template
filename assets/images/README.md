# Assets

Default placeholder assets are included so `app.config.ts` paths work out-of-the-box.
Replace these files with your own brand assets before production release.

| File | Purpose | Recommended spec |
|------|---------|------------------|
| `icon.png` | App icon | 1024×1024 |
| `android-icon-foreground.png` | Android adaptive foreground | 1024×1024, transparent background, centered logo |
| `android-icon-background.png` | Android adaptive background | 1024×1024, solid background color |
| `android-icon-monochrome.png` | Android adaptive monochrome icon | 1024×1024, monochrome glyph on transparent |
| `splash-icon.png` | Splash image mark | 512×512 or 1024×1024 on dark/black background |
| `notification-icon.png` | Android notification icon | 96×96, white glyph on transparent |
| `favicon.png` | Web/favicon placeholder | 48×48 |
